### Compiled VS Interpreted Languages
- C++, Rust is a complied language -> has a single pass compiler
  * compiler : reads your entire code first, translates to machine code, then runs it
- Python is an interpreted language -> executes code line by line
  * Interpreter: reads and run code ***line by line***
